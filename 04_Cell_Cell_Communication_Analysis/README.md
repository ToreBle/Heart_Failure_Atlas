# 04 – Cell cell communication analysis

Scripts for cell-cell communication analysis.

## Scripts

- **`<CCI_LIANA_GPCR_CrosstalkR>.R`** – Addition of the GPCR module for LIANA.
- **`<CrossTalkR_Clustering>.R`** – CrossTalkR analysis for disease-specific cell-cell communications.
- **`<MultiNicheNet_Heart_Atlas>.R`** – MultiNicheNet analysis of the main cluster of the human heart failure atlas.
- **`<MultiNicheNet_Downstream>.R`** – Visualizations of the MultiNicheNet analysis.
