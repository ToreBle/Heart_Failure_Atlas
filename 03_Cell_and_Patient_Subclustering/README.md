# 03 – Cell and patient subclustering

Scripts for subclustering and patient-centered analysis of the human heart failure atlas.

## Scripts

- **`<Heart_atlas_Subclustering>.nbconvert.ipynb`** – Script for the subclustering of each cell type.
- **`<Cell_type_compositions_Subcluster>.ipynb`** – Definition of subcluster resolutions and compositional analysis.
- **`<Pseudobulk_Heart_Failures>.R`** - Pseudobulk DEG analysis for the main cluster and disease conditions.
- **`<Pseudobulk_Subcluster.R>.R`** - Pseudobulk DEG analysis for the subclusters of the human heart failure atlas.
- **`<PanPy_Atlas_Patient_level_aggregation>.ipynb`** – Patient-based clustering approach.
- **`<PanPy_Patient_Clustering_Visualizations>.ipynb`** – Visualizations of the patient-based clustering approach.
