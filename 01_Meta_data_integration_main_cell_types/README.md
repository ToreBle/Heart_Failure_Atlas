# 01 – Metadata Integration and Main Cell Types

Scripts for quality control, metadata harmonization, integration, and annotation of the major cardiac cell populations in the human heart failure atlas.

## Scripts

- **`<Data_curation_heart_atlas>.ipynb`** – Harmonization of each dataset before integration.
- **`<scVI_integration_human_heart_atlas>.ipynb`** - scVI integration of the human heart failure atlas.
- **`<Integration_Benchmarking>.py`** – Benchmarks scVI, Harmony, and BBKNN integration using ARI, NMI, iLISI, and cLISI.
- **`<Meta_Data_Analysis_Heart_Atlas>.R`** – Analysis and plotting of the harmonized clinical meta data.
- **`<Cell_type_compositions_major_cell_types>.ipynb`** - Cell type composition analysis for the major cell types with sccoda.
